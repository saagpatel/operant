# Open Sittings build record

How OPERANT Open Sittings was planned and built: the shared contract (`packets/00-contract.md`),
the amendments after the read-only stress test (`packets/00b-contract-amendments.md`,
`stress-test.md`), and every work packet given to a worker, including the review-fix packets. Formats in
the code are authoritative; these files explain why they look the way they do.
